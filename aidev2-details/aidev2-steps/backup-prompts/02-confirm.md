## Step 2 - Confirm

Before writing, use `vscode_askQuestions` to confirm execution.

Use:
- header: `confirm`
- question: `Run backup script to refresh framework-ai-blueprint-template-v2/user-prompts-content from local user prompts. Proceed?`
- options:
  - `Yes, replace now`
  - `No, cancel`

If the user chooses cancel, stop with no changes.
