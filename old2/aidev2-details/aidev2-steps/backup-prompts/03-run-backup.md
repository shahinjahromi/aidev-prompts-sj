## Step 3 - Execute

Run the appropriate script for the current OS from FRAMEWORK_ROOT:

Linux/WSL:
```bash
bash "${FRAMEWORK_ROOT}/scripts/backup-user-prompts-linux.sh"
```

Windows:
```pwsh
& "${FRAMEWORK_ROOT}\scripts\backup-user-prompts-windows.ps1"
```

Do not run extra copy, delete, or sync commands outside this script.
